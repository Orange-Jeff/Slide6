Diamond Slide 5 - Help Guide

🎯 Game Objective

Connect 4 or 5 pieces in a row (depending on game settings) by dropping pieces from the edges of the diamond-shaped board. Pieces slide until they hit another piece or the board edge.

🎮 How to Play

Making Moves

  • Click on any orange selector around the board edges
  • Keyboard: Use 1-6 for top selectors, A-F for bottom selectors
  • Arrow Keys: Navigate between selectors, Space or Enter to drop

Game Modes

  • Online Game: Play against other players worldwide
  • vs Computer: Play against AI opponent
  • Local 2-Player: Pass-and-play on same device

🌐 Online Multiplayer

Creating Games

  • Enter a room name and select game settings
  • Click "Create Room" to start hosting
  • Share the game URL with friends

Joining Games

  • Browse available games in the lobby
  • Click any game to request to join as player or watcher
  • Wait for the host to approve your request

Watching Games

  • Select "Watch" when requesting to join a game
  • Watch live gameplay without participating
  • Watcher count is displayed in the game

🎲 Game Features

Diamond Board

  • 6x6 grid rotated 45 degrees for unique gameplay
  • Pieces slide from edges until they hit obstacles
  • Strategic placement creates blocking opportunities

Game Controls

  • New Game: Start fresh without returning to lobby
  • Forfeit: Concede the current game
  • Save/Load: Save game state for later
  • AI Analysis: Export game for advanced analysis

🔧 Tips & Strategy

  • Control the Center: Central positions offer more connection opportunities
  • Block Opponents: Watch for their potential winning moves
  • Plan Ahead: Consider how pieces will slide and stack
  • Use Edges: Edge positions can be harder to block
  • Create Forks: Set up multiple winning threats simultaneously

🎵 Sound Effects

The game includes immersive sound effects for:

  • Piece dropping and sliding
  • Pieces being pushed off the board
  • Victory celebrations

Note: Make sure your browser allows audio playback for the best experience.

❓ Troubleshooting

Connection Issues

  • Refresh the page if games don't load
  • Check your internet connection for online games
  • Try creating a local game if server is unavailable

Game Not Responding

  • Make sure it's your turn (check the turn indicator)
  • Try clicking directly on selectors instead of using keyboard
  • Refresh the page to reconnect to online games

✏️ Customization

This game is open source and can be modified to suit your needs! Feel free to:

  • Change colors, fonts, and styling in style.css
  • Adjust game rules and AI behavior in game.js
  • Customize the board size or win conditions
  • Add your own sound effects
  • Modify the UI layout in the HTML files

The code is well-commented and designed to be hackable!
