# Diamond Slide 6

A sliding pieces puzzle game — tap, slide, and solve your way through sparkling diamond grids.

## How to play

Slide the diamond tiles around the grid to arrange them in the correct order. One empty space, endless possibilities — plan your moves!

- 🖱️ Click or tap a tile next to the empty space to slide it
- 💎 Match the diamonds into their target pattern to win
- 🔊 Sound effects for every slide, drop, and win

## Run it yourself

No build step, no dependencies — just open it in a browser:

```bash
git clone https://github.com/Orange-Jeff/Slide6.git
```

Then open `game.html` (or `index.html`) in any modern browser. That's it.
